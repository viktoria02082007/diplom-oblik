# Розробка вебзастосунку для інформаційної підтримки обліку й управління торговельною діяльністю з реалізації плодоовочевої продукції

## Загальна інформація про проєкт
* **Тип проєкту:** Кваліфікаційна робота на підтвердження ступеня фахового молодшого бакалавра.
* **Дипломний керівник:** Бабич О.В.

---

## Вихідні дані до роботи
Розроблений програмний продукт має являти собою вебзастосунок для інформаційної підтримки обліку та управління торговельною діяльністю з реалізації плодоовочевої продукції. Застосунок має забезпечувати введення, редагування та пошук даних про продукцію, постачальників і клієнтів, а також формування звітності щодо залишків, продажів та фінансових результатів. 

Функціональність застосунку має відповідати чинній правовій базі України у сфері торгівлі, бухгалтерського обліку та захисту персональних даних. При розробці слід подбати про зручний інтерфейс для різних категорій користувачів, багатокористувацький доступ з механізмами авторизації та можливість роботи у вебсередовищі з доступом у реальному часі. Для реалізації проєкту доцільно використати сучасні програмні засоби веброзробки, реляційні бази даних та хмарні сервіси для адміністрування й зберігання інформації.

---

## Використані технології
* **Мова програмування та бекенд:** Java
* **Веброзробка (Фронтенд):** HTML5, CSS3, JavaScript
* **Бази даних:** Реляційні БД
* **Інструменти розробки:** Інструментарій JetBrains
* **Система керування версіями:** Git / GitHub

## Календарний план (Етапи розробки)
Відстеження статусів виконання завдань ведеться на Канбан-дошці у розділі **Projects**:
1. Систематизація матеріалу, накопиченого під час переддипломної практики. Написання реферату та вступу.
2. Написання теоретичної частини (основні розділи пояснювальної записки).
3. Проектування системи. Побудова діаграм. Розробка додатків.
4. Написання коду застосунку.
5. Вибір методів тестування. Написання тест-кейсів та їх реалізація.
